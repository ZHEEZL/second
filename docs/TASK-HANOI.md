## Контракт

```csharp
public readonly record struct HanoiMove(int Disk, int From, int To);

IReadOnlyList<HanoiMove> Solve(int diskCount, Action<HanoiMove>? onMove = null);
```

- Стержни: `0 = A`, `1 = B`, `2 = C`; старт — все кольца на A, цель — C.
- Диски: `1` — самый маленький, `diskCount` — самый большой.
- Валидное решение: `2^n − 1` ходов, никогда не кладём большее на меньшее,
  переносим по одному кольцу.
- UI сам проигрывает ходы: перекладывает кольца и обновляет счётчики.
  `onMove` можно использовать для лога, но не обязательно.

## Рекурсивный вариант

```text
Move(n, from, to, aux):
    если n == 1: перенести диск 1 с from на to; вернуть
    Move(n − 1, from, aux, to)
    перенести диск n с from на to
    Move(n − 1, aux, to, from)
```

Вызов: `Move(diskCount, 0, 2, 1)`. Число ходов `2^n − 1` можно посчитать
заранее и сверить.

## Вариант через стек (доп. задание)

Нужен **явный стек** вместо рекурсии. Идея: хранить кадры вида
`(n, from, to, aux, stage)`, где `stage` показывает, на каком шаге находится
обработка кадра. Цикл `while (stack.Count > 0)`:

- `stage 0` → положить кадр `(n−1, from, aux, to, 0)`, перейти в `stage 1`;
- `stage 1` → сделать ход диска `n`, перейти в `stage 2`;
- `stage 2` → положить `(n−1, aux, to, from, 0)`, снять кадр.

Рекурсию в `StackHanoiSolver` использовать нельзя — преподаватель может
проверить.

# Задача: H-дерево (фрактал)

**Статус:** готово (референсная реализация). **Автор:** команда.

## Что это

Классический рекурсивный фрактал: сначала рисуется буква H, затем в каждом из
четырёх её концов — такая же H, уменьшенная в `√2` раз, и так до заданной
глубины. Глубина 0 — ровно одна буква H.

## Где код

- Алгоритм: `src/RecursiveLab.Core/Tasks/HTree/HTreeGenerator.cs`
- Отрисовка: `src/RecursiveLab.App/Controls/HTreeCanvas.cs`
- Страница: `src/RecursiveLab.App/Views/Pages/HTreePage.axaml(.cs)`

## Формулы

| Величина | Формула |
|----------|---------|
| Отрезков | `S(0) = 3`, `S(d) = 4·S(d−1) + 3` ⇒ `S(d) = 4^(d+1) − 1` |
| Букв H | `(4^(d+1) − 1) / 3` |
| Размер следующей H | `size / √2` |
| Сложность | `O(4^d)` по времени и памяти |

Пример: глубина 4 — 341 буква H, 1023 отрезка; глубина 6 — 5461 H, 16 383 отрезка.

## Как устроена рекурсия

```csharp
Build(cx, cy, size, level):
    нарисовать 3 отрезка H с центром (cx, cy)
    если level == maxDepth: return
    childSize = size / √2
    Build(cx − size/2, cy − size/2, childSize, level + 1)
    Build(cx + size/2, cy − size/2, childSize, level + 1)
    Build(cx − size/2, cy + size/2, childSize, level + 1)
    Build(cx + size/2, cy + size/2, childSize, level + 1)
```

Отрезки складываются в список в порядке обхода (сначала ствол, потом
поддеревья). Именно поэтому анимация «Построить» рисует фрактал в порядке
рекурсивных вызовов.

## Что должен уметь UI

- Глубина 0–6 (слайдер), пересчёт без подвисаний.
- «Построить» — анимация от 0 до полного числа отрезков; «Сброс» — очистить.
- «Скорость» меняет длительность; прогресс-бар и счётчики обновляются.
- HUD показывает глубину, число видимых отрезков и статус.
- Кнопка «Открыть HTreeGenerator.cs» открывает файл в проводнике.

## Как заменить реализацию на свою

Если хотите сдать собственный вариант:

1. Отредактируйте `HTreeGenerator.Generate` — сохраните сигнатуру и порядок
   обхода (ствол → четыре поддерева). UI не придётся менять.
2. Прогоните `dotnet test` — тесты `HTreeGeneratorTests` проверяют число
   отрезков, уровни, длины и габариты.
3. Проверьте визуально глубины 0–6 и анимацию.

## Что говорить на защите

- Почему уменьшение именно в `√2`: соседние H становятся меньше в `√2` раз,
  как в классическом определении H-дерева.
- Почему `S(d)=4·S(d−1)+3`: на каждом уровне добавляются четыре поддерева и
  три отрезка текущей H.
- Почему это рекурсия, а не цикл: структура самоподобна, каждый вызов
  обрабатывает одну H и делегирует четыре независимые подзадачи.
